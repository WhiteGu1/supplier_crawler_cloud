# Kandel PDF 解析器创建记录

## 时间
2026-07-13 19:00

## 任务
为 kandel 供应商创建 PDF 目录解析器，类似 dsaza 的导入方式。

## PDF格式分析
- 文件: `Catalogo080726.pdf`，487页，53MB
- 页面尺寸: 792×612 (横向)
- 前2页为封面（纯图片无文字）
- 内容页: 4列×2行布局，每页8个商品
- **奇偶页交替偏移**: 偶数内容页(x0≈57起偏右)，奇数内容页(x0≈25起偏左)
- 页眉有分类: 第一行大类(如"BATH COLLECTION")，第二行子类(如"ACCESORIOS")
- 每个商品: SKU(5-7位数字+可选字母) + `$` + 价格(阿根廷格式 `$.###,##`) + 名称描述(多行)
- 图片: 每个商品一张，在SKU行上方

## 实现内容
- 创建 `crawler/pdf_parsers/kandel.py`
- 插件系统自动发现，无需额外注册
- 奇偶页偏移通过 `(page_idx - 2) % 2` 判断
- 名称收集: SKU行下方80px内，去除 B:数字 M:数字 包装信息
- 图片匹配: 按列边界+x坐标对齐

- 名称完整率: 100%

- 分类数: 192个
- 价格范围: $672 ~ $684,000
