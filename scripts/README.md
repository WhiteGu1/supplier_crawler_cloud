# 项目历史与维护脚本目录 (`scripts/`)

本目录存放项目在日常运营、历史分类及系统维护中沉淀的辅助脚本与批次数据。

---

## 子目录说明

### 1. `classification_batches/` (商品分类批次)
包含商品分类相关的辅助脚本与中间批次数据：
- `apply_*.py`: 将分类结果批量回填入库的脚本（按批次/供应商划分）。
- `classify_*.py` / `reclassify_*.py`: 调用模型或规则对未分类商品进行分类的脚本。
- `panda_batch_*.json`, `kk_batch_*.json`, `diego_*.json`: 历史分类处理过程数据。
- `uncat_batches/`, `toy_batches/`, `classify_cache/`: 批次缓存与提示词记录。

### 2. `maintenance/` (运维与校验工具)
包含系统日常维护、数据检查、排错与对账脚本：
- `check_*.py` / `check_*.ps1`: 数据一致性与进度检查工具。
- `fix_*.py`: 价格历史修复、分类对齐与异常状态修复工具。
- `verify_*.py`: 商品编码、图片和数据完整性校验工具。
- `test_*.py`: 各模块与接口功能单测脚本。

### 3. `temp/` (临时与调试文件)
包含网页抓取调试快照、输出文本日志及临时导出文件。
